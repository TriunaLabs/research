# Observations

Field notes from real working sessions.

These are **not** articles. Articles in this repository ship with the code and data
behind them so their claims can be checked. An observation has neither: it is a
qualitative record of something that happened once, written down because it was
informative, and published so that the reasoning it later supports has a visible
origin.

Each record states plainly what it does and does not support. Where a record
motivates an instrument that would turn it into a measurement, it says so, and the
measurement — if it is ever made — belongs in `articles/` rather than here.

Sessions described here are abstracted. Project names, file paths, product details
and business context are removed; the structure of what happened is what matters and
is all that is kept.
